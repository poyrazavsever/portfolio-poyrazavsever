# Portfolio-Obsidian

Bu proje, portföy ve içerik yönetimi amacıyla Next.js tabanlı olarak geliştirilmiştir. Deneme ve geliştirme amaçlı hazırlanmıştır. Gerçek bir ürün ortamında kullanılmadan önce kapsamlı testlerden geçirilmelidir.

## Özellikler

- Next.js ile modern ve hızlı bir kullanıcı deneyimi
- Çoklu dil desteği (i18n)
- Modüler ve ölçeklenebilir dosya/folder yapısı
- Kolay içerik yönetimi için admin paneli
- Blog, medya, ürünler, referanslar ve daha fazlası

## Klasör Yapısı

Proje, aşağıdaki ana klasör ve dosya yapısına sahiptir:

- `app/` : Sayfalar ve route yapısı
- `components/` : Yeniden kullanılabilir bileşenler
- `data/` : Statik veri dosyaları
- `dictionaries/` : Çoklu dil sözlükleri
- `hooks/` : Özel React hook'ları
- `lib/` : Yardımcı fonksiyonlar ve kütüphaneler
- `public/` : Statik dosyalar (görseller, PDF vb.)
- `supabase/` : Supabase SQL ve migration dosyaları
- `types/` : TypeScript tip tanımlamaları
- `docs/` : Proje dokümantasyonları

## Kurulum

1. Bağımlılıkları yükleyin:
   pnpm install
2. Geliştirme sunucusunu başlatın:
   pnpm dev

## Not

Bu proje, deneme ve geliştirme amaçlıdır. Katkıda bulunmak veya incelemek serbesttir.
